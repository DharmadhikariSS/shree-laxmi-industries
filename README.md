# Shri Laxmi Industries — Official B2B Website
**Official Domain**: [https://shrilaxmiindustries.co.com](https://shrilaxmiindustries.co.com)

B2B manufacturing website for **Shri Laxmi Industries** (Crumb Rubber & Polymers Unit), located in Ahmadpur MIDC, Latur, Maharashtra.

## Key Features & Highlights
- **Minimalist Industrial Aesthetic**: Clean typography (Inter + JetBrains Mono), spacious layout, zero clutter, and restrained industrial palette (Charcoal, Pure White, Slate, and Forest Green).
- **Factory Setup Transparency**: Dedicated Ahmadpur MIDC, Latur greenfield progress tracker and Maharashtra State PSI Incentive notice.
- **Product Range & Mesh Specs**:
  - 10–20 Mesh (0.85 – 2.00 mm): Road base underlayment, sports turf infill, playground tiles.
  - 20–40 Mesh (0.425 – 0.85 mm): CRMB asphalt paving, running tracks.
  - 40–60 Mesh (0.25 – 0.425 mm): Molded rubber goods, conveyor belts, footwear soles.
  - 60–80 Mesh (0.18 – 0.25 mm): Precision compounding & virgin polymer extension.
- **Interactive Technical Data Sheet (TDS) Modal**: Click "Download Specs PDF" to view or print the official ASTM D5603 / IRC:SP:53 compliance specifications.
- **Direct RFQ & WhatsApp Desk**: Interactive RFQ submission with instant ticket generation and WhatsApp message pre-fill for procurement managers.
- **Zero-Dependency & Portable**: Can be opened directly by double-clicking `index.html` or served with any HTTP server.

## How to Run Locally

### Option 1: Direct File
Simply double-click [index.html](file:///d:/Vibe%20coding%20projects/Shri_Laxmi_Industries/index.html) in your browser.

### Option 2: Node.js (Live Server)
```bash
node server.js
```
Then visit [http://localhost:3000](http://localhost:3000).

### Option 3: Python
```bash
python -m http.server 3000
```
